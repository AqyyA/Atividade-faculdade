# TINDER

**Descrição**
App de relacionamentos com geolocalização, onde usuários dão “swipe” em perfis e formam “match” quando há interesse mútuo, liberando um chat.

Público-alvo: Adultos 18+ buscando encontros, relacionamentos ou networking social.

Principais funcionalidades: Perfil com fotos/bio, swipe por geolocalização, matches e chat, filtros de busca, verificação de perfil, planos premium (Super Like, Boost).

Tecnologias utilizadas: iOS (Swift) / Android (Kotlin), backend em microsserviços, banco NoSQL, APIs de geolocalização, infraestrutura em nuvem (AWS).

Requisitos para utilização: Smartphone com internet, cadastro via e-mail/telefone/rede social, 18 anos ou mais, permissão de localização ativada.
